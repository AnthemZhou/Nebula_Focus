# Nebula Focus iPhone 测试

这里全部是虚构样例。请先在「设置 → 第三方插件」启用 Nebula Focus，并确认 Bases 核心插件已开启。

这些页面只用本地附件，不需要网络服务。请记录 iPhone 型号、iOS、Obsidian 与测试包版本；桌面移动模拟不能代替真机验收。

## 项目看板

检查：横向滑动、打开卡片、新建、触摸更改状态，以及新建后的撤销与重做。

![[Bases/项目看板.base]]

## 想法收集箱

检查：长标题、标签、缩略图、键盘弹出后的编辑和弹窗位置。使用命令面板中的「撤销数据库操作」与「重做数据库操作」检查无外接键盘的流程。

![[Bases/想法收集箱.base]]

## 图片画廊

检查：封面取自正文第一张图；没有图片时不显示空白封面区域。

![[Bases/图片画廊.base]]

## 简短验收

1. 在每个视图切换横竖屏，确认文字未缩小、控件可以点击。
2. 横向滑动表格，不应误打开笔记或进入输入。
3. 输入中文标题、取消一次、保存一次，检查输入法候选词。
4. 选中多个标签，显示与收起软键盘，检查面板仍可操作。
5. 新建 → 修改属性 → 撤销两次 → 重做两次，核对顺序。
6. 向下滚出数据库再返回，重复撤销；切到另一页时不能误撤销原页。
7. 暂时离开应用、锁屏后返回，检查视图。应用进程若重启，撤销会话结束。
8. 关闭插件，确认原生 Bases 仍可打开这些普通 Markdown 记录。

发生问题时记录操作、期望结果和实际结果。测试库可以修改；不要用它替换自己的正式笔记库。
