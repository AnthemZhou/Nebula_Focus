# Direction

Use Obsidian to validate quiet reading and personal context storage, reusing native files, links and attachments. Consider an independent app only when actual platform constraints justify it. Do not build a replacement editor/database/sync stack speculatively.

0.6.0 validates portable page layout, direct section editing, source-order drag, covers and simple linked-note cards. Next gate is real-device feedback and data-safety verification before publishing.

Future modules remain separate decisions: structured video metrics, original-statement-backed ledgers, versioned shot/asset references, scoped AI context export, richer inline editing, attachment-aware page packaging. None are implemented or promised by the version number.
