# Nebula Focus 1.0.0 — Notion-like native Bases UI

1.0.0 将当前原生数据库界面优化作为完整产品，不包含旧版写作布局、导航器、资料库管理或格式速查。

- 发布平台、内容类型、项目等语义字段自动显示为彩色标签，原生编辑与关系链接仍可使用。
- 想法收集箱使用紧凑、自适应行高；文字换行，标签完整显示，缩略图不撑大整行。
- 点击想法标题原位编辑，点击页面图标或「打开」进入笔记；点击列名原位编辑显示名称。
- 紧凑的彩色标签选择面板支持搜索、创建、移除、拖动排序和键盘排序。
- 卡片/看板采用正文第一张图片作封面，逾期日期标红，提供原生新建入口。
- 通过 ⌘⌥U / Ctrl+Alt+U 即时切换优化与原生外观。

显示和切换不会改写 Markdown 正文。用户主动修改数据时，通过原生 Bases 事务更新 YAML；样式与候选项顺序保存在插件侧，外部 `.base` 保存视图设置。AI 仍可直接读取 Markdown/YAML。

Notion 导出未保留完整属性 schema，因此彩色标签根据语义字段识别，不声称还原 Notion 全部数据库类型。针对原生内部视图的适配有结构检查；无法识别时保留原生控件。

最低 Obsidian 1.14.4，实测桌面版 1.14.5。移动端不在本版范围。附运行包、源码包、通用示例库及 SHA-256 清单；私人笔记和迁移备份不包含在发布内容中。

构建与 86 项自动测试通过。实机验证标题原位编辑/取消、打开笔记、标签呈现和快捷键切换；验收前后 307 个内容文件的 SHA-256 完全一致。
