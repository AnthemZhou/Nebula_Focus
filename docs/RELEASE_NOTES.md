# Nebula Focus 0.8.0 — 连续编辑与恢复 · experimental prerelease

标题、段落和列表项继续在原位编辑，保持阅读时的字体与间距，隐藏 Markdown 标记。此次补齐日常书写流程和异常恢复。

- Cmd/Ctrl+Z、Shift+Cmd/Ctrl+Z 与 Ctrl+Y 支持输入及保存后的撤销重做，保留光标与原始 Markdown 字节；撤销拆分会保留之前输入的文字。
- Backspace/Delete 合并相邻同类段落与简单列表项，方向键在边界切换文字块；空列表或引用回车退出。
- 轻量文字样式菜单支持正文、一级至三级标题、列表、待办、引用、粗体和斜体，不添加正文编辑框。
- 不同编辑分别保留恢复草稿；保存一个块不会清除其他块的草稿。旧版缓存自动兼容，每篇最多 20 份，不静默淘汰。
- 多行粘贴及结构转换先缓存完整操作结果，磁盘失败后可重试；外部文件冲突仍拒绝覆盖。
- 修复 Setext 标题、引用链接、字面实体、代码空格、硬换行、相邻粗体及嵌套列表延续的 Markdown 保真问题。

90 项自动测试和真实 Mac Obsidian 的 56 项检查全部通过；验证范围、原始报告与界面截图见 docs/TESTING.md。撤销历史在内存中保留，重启后清空；复杂嵌套格式转换继续使用原生编辑器。iPhone/Android 实机与第三方主题仍待验证。

附安装包、完整源码、示例库、离线交互预览与 SHA-256 校验。GPL-3.0-only，依赖许可证随源码和 main.js 保留。桌面使用时请关闭“仅在手机和平板启用”。
