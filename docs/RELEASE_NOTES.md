# Nebula Focus 0.9.0 — 连续写作与独立资料库

正文改成一整篇连续书写的文稿。使用 Obsidian 原生实时阅览编辑器，移除逐块进入编辑、完成、取消的流程。标题和常用文字格式的标记保持隐藏，光标进入标题时排版不跳动。

资料库成为独立入口，使用原生 `.base` 文件提供表格和卡片。

- 普通笔记不自动新增属性，写作页面默认隐藏属性区域。
- 收录只保存引用；同一篇笔记可以加入多个资料库，正文不用移动或复制。
- 添加字段只新增空列，填写值时才写入对应笔记的 YAML。
- 移出资料库保留笔记及其属性；插件运行时跟踪笔记和文件夹改名。
- 修复原生数据库延迟保存可能覆盖新增收录项的问题。
- 旧版封面、分栏和逐块编辑保留为可选兼容模式，已有资料和恢复草稿保留。

在实际 Mac Obsidian 1.14.4 中验证中文组合输入、跨段落选取、撤销重做、属性隔离、数据库保存与深浅主题的窄屏布局。完整结果见 docs/TESTING.md。iPhone / Android 真机和第三方主题仍待验证。

最低 Obsidian 1.9.0；资料库需要启用“数据库 / Bases”核心插件。桌面使用时关闭“仅在手机和平板启用”。附安装包、源码、示例库、真实截图离线预览和 SHA-256 校验。GPL-3.0-only，实验性预发布。
