# Nebula Focus 1.6.0

## 中文

- 导入 Notion 的 Markdown 与 CSV 时，可将核对过的数据库字段保存在笔记开头的 YAML，保留正文及附件的相对链接。
- 使用配套的规则文件在本地计算公式和关联汇总。可在页面展示实时结果，也可用「更新本地表格核算值」将结果写回 Markdown，供 Bases 和外部 AI 读取。
- 数据库视图支持导入字段选项与颜色、筛选、分组、列宽和冻结列。记录布局也可直接在笔记的 YAML 中声明。
- iPhone 页面底部可直接输入 AI 记录或添加截图。窄分栏中的正文和数据库工具随宽度换行。

需要 Obsidian 1.14.5 或更高版本。手动安装请下载 `nebula-focus-1.6.0.zip`，解压到库的 `.obsidian/plugins/` 目录。升级时保留已有的 `data.json`。

## English

- Recognize Notion Markdown and CSV exports. Verified properties go into YAML frontmatter, with the original body and relative links preserved.
- Display local formula and rollup results from a supplied rule file. An explicit command writes updated results to Markdown for Bases and external AI tools.
- Import database filters, groups, column widths, frozen columns and option colors. Record layouts can live in note frontmatter.
- Capture text or screenshots from the iPhone AI composer. Prose and database controls reflow in narrow panes.

Requires Obsidian 1.14.5 or later. Extract the plugin ZIP into your vault’s `.obsidian/plugins/` folder. Keep your existing `data.json` when upgrading.
