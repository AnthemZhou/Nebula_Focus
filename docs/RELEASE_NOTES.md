# Nebula Focus 0.9.2 — 底部格式速查

- 格式速查从当前写作画布的底部居中浮起，随分屏与画布尺寸变化保持位置。面板宽度最多 640px，在画布内保留 12px 边距。
- 放大符号与格式名称，改为“段首 / 文字”两组。段首的 8 张卡片在宽画布中排成四列、窄画布中排成两列；“文字”集中展示斜体、加粗与高亮。
- 采用 240ms 入场、140ms 退场的轻微位移与淡入淡出。遵循系统“减少动态效果”设置；关闭后立即结束交互，快速重开、切换视图与停用插件时清理旧面板。
- 保留单独按住 Shift 约 0.6 秒显示、松开收起的操作。长按时不抢编辑焦点；Shift + 8、Shift 选字与中文输入法保留正常行为。
- 「更多 → 格式速查」与命令面板可持续显示速查，Esc 关闭并回到正文；分组支持方向键、Home / End。速查及分组切换均为只读，不修改文稿。
- 矮窗口可以滚动查看卡片；极矮窗口改为整体滚动，避免内容被挤没，字号保持不变。

保留上一版对普通段落开头未配对 `*` 的显示修复：星号可见，配对后正常显示斜体，星号加空格仍创建列表。跨行已配对强调、有效嵌套强调、代码与转义维持原有行为；不改 Markdown，也不修改 Obsidian 的全局自动配对设置。连续写作、原生保存与撤销、独立资料库及可选旧版页面布局继续保留。

本版真实 Mac Obsidian 检查 **27/27** 通过，单元测试 **130/130** 通过，覆盖速查交互、布局与动效等变化。0.9.1 的连续写作 24 项检查属于历史验证，不计入本版重跑。详细结果见 [验证记录](TESTING.md)。

普通文稿仍不自动增加属性，资料库仍是独立入口。最低 Obsidian 1.9.0，实际测试 1.14.4。iPhone / Android 真机及第三方主题仍待验证。附安装包、源码、示例库、实际截图离线预览与 SHA-256 校验。GPL-3.0-only，实验性预发布。
