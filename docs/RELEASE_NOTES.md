# Nebula Focus 0.7.0 — 原位逐段编辑 · experimental prerelease

点击标题、段落或列表项时，直接在原来的文字位置编辑，不再把整个分区展开成 Markdown 文本框。参考 Effie 官方说明中的即时呈现与简洁编辑交互，保留 0.6.1 的整体视觉风格。

- 一个标题、一段文字或一个列表项分别编辑；标题的 `#` 标记保留在文件中。
- 进入和退出编辑使用同一个文字元素，保留字体、间距、粗体与链接；完成、取消位于角落，不挤动正文。
- Enter 新建下一段或列表项，Shift+Enter 段内换行；多行纯文本粘贴分段；Cmd/Ctrl+B、I 设置粗体、斜体。
- 修复真实 Obsidian 保存后刷新整页、打断新段落和光标的问题；连续点击不同段落会等待上一段保存。
- 外部冲突检查、取消后的恢复草稿、原生编辑器回退继续保留。代码、表格、公式、嵌入等复杂内容使用原生编辑器。

在 macOS 26.5.2 / Obsidian 1.14.4 中完成真实应用回归、中文组合输入及 320/393/1024px 深浅色布局测量。标题和段落的进入、退出编辑位置与样式保持一致。原始报告、截图与具体测试范围见 docs/TESTING.md。

提供安装包、完整源码、示例库及校验文件。桌面端请关闭“仅在手机和平板启用”。仍为预发布，iPhone/Android 实机与第三方主题尚待验证。GPL-3.0-only；新增解析依赖的许可证随安装包和 main.js 保留。
